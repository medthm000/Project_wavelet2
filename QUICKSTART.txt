🔧 TROUBLESHOOTING:

  Problem: "npm: command not found"
  → Solution: Restart PowerShell after Node.js install

  Problem: "Port 3000 in use"
  → Solution: Edit vite.config.ts, change port to 3001

  Problem: Charts not rendering
  → Solution: Wait for npm install to complete fully
